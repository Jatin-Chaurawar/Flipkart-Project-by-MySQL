# 📊 Flipkart Mobile Data Analysis Using SQL

Welcome to the **Flipkart Mobile Data Analysis** project! This project demonstrates how SQL can be used to analyze mobile phone data from Flipkart to derive actionable insights about pricing, customer reviews, and brand performance.

---

## 📌 Project Overview

This project focuses on querying and analyzing structured e-commerce data using SQL. It helps uncover trends in mobile pricing, user ratings, review volumes, and discount strategies, which are critical for understanding market behavior.

---

## 🎯 Objectives

- Extract key insights using optimized SQL queries
- Identify top mobile brands and models by various performance metrics
- Use SQL for trend analysis and business decision support
- Visualize the data through presentations and charts
- Lay the groundwork for integration with Python and ML in future phases

---

## 📈 Insights & Observations

- 📱 Premium brands have high MSP but usually offer minimal discounts.
- ⭐ Most reviewed phones are not always the highest rated.
- 💰 Budget models attract higher discounts and generate more sales volume.
- 🔍 Customer reviews and ratings are vital in determining brand perception.

## 📂 Files in This Repository
